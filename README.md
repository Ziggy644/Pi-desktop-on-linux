# Pi-desktop-on-linux
Script to install/update Pi Desktop on linux and receive node bonus
Tested on ubuntu 24.04

# Requirements

-python 3.x\n
-virtualization enabled in BIOS \n
-Docker (installed via ./run command) \n
-p7zip (installed via ./run command) \n

# Installation

git clone .git
cd Pi-desktop-on-linux
chmod +x ./run
